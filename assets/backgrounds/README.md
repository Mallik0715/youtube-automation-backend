# Backgrounds

Painted backgrounds for the videos, one per place + lighting (1080x1920, vertical).
The current files are free AI placeholders. To upgrade one:

1. Open **Microsoft Designer** (designer.microsoft.com) or **Bing Image Creator** (bing.com/create) - free.
2. Choose a **portrait / 9:16** size if the tool offers one, and paste the prompt below.
3. Pick the best of the images and download it.
4. Save it here with **exactly** the file name shown (replace the old one), then commit and push.

Every video rendered after that uses your new image. Missing images fall back to the code-drawn scene.
Tip: keep the floor area in the bottom third empty - the characters stand there.
