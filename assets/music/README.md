Background music for this channel. One `.mp3` from this folder is picked at random for each video
and mixed about 15 dB below the narration.

Included tracks (original, synthesized from scratch, 100% royalty-free, no copyright claims):
- warm_lofi.mp3 - warm lo-fi electric piano (Fmaj7 / Em7 / Dm7 / Cmaj7, 72 BPM)
- soft_piano.mp3 - soft piano arpeggios (Am / F / C / G, 66 BPM)

To add more: drop any royalty-free `.mp3` here (YouTube Studio → Audio Library, or Pixabay Music).
Delete a file to stop it being used. If the folder has no `.mp3`, a quiet generated pad is used instead.
